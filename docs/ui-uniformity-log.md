# UI uniformity: what was done, step by step

The work in `docs/ui-uniformity-plan.md`, done 2026-10-14 without commits (Scott reviews and commits). Each step
below has a **snapshot**: a git tree object recorded while the work was in progress, so the steps can be reviewed
and committed one at a time even though they all sit in one working tree:

```
git diff <previous tree> <tree> --stat        # what one step changed
git diff <previous tree> <tree> -- <path>     # one file
```

(The trees are objects in this repo's `.git`; `git gc` keeps them for two weeks unless referenced. To keep one,
`git tag ui-step-N <tree>` is enough.) Harness: every step was replayed on all five fixtures (`--redirect-ports
--control`, gen2 on the local recording) and diffed against the step before; the result is given per step.
